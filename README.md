# Урок 3. Игровая библиотека
В проекте мы берем API RAWG и достаём от туда  игры с необходимыми даннами.

## Как установить

Python3 должен быть уже установлен. 
Затем используйте `pip` (или `pip3`, есть конфликт с Python2) для установки зависимостей:
```
pip install -r requirements.txt
```

Получить ключ вы можете перейдя по ссылке [RAWG](https://rawg.io/apidocs), нужно зарегестрироваться и в личном кабинете вам будет выдан `api_key`.

### Переменные окружения
Часть настроек проекта берётся из переменных окружения. Переменные окружения — это переменные, значения которых присваиваются программе Python извне. Чтобы их определить, создайте файл .env рядом с main.py и запишите туда данные в таком формате: ПЕРЕМЕННАЯ=значение.

Пример содержания файла .env:
```
API_KEY='api_key'
```

## Как Запустить проекта

Для запуска проекта впишите в терминал:
```
python main.py
```
